# 규정 새로고침 이용 안내

규정 담당자가 **https://rulef5.k-union.kr** 에서 기능을 직접 써 볼 수 있도록 순서대로 정리한 안내서입니다. 설치·로그인 없이 브라우저로 씁니다.

> 모든 결과는 **AI 초안**입니다. 담당자가 원문과 대조해 확정해야 합니다. 민감정보·개인정보는 입력하지 마세요.

---

## 1. 처음 시작하기

1. 접속하면 <b>시작 화면(F5)</b> 이 열립니다.
2. <b>「어느 기관에서 쓰시나요?」</b> 에서 기관 유형을 고릅니다. 유형에 따라 절차 단계와 서식이 달라집니다.

   | 유형 | 대상 규정 | 절차·서식의 차이 |
   |---|---|---|
   | 공공기관 | ALIO 공시 내규(정관·규정·지침) | 규정심의위원회·이사회, ALIO 내부규정 공시 |
   | 중앙행정기관 | 훈령·예규·고시(법제처 행정규칙) | 행정예고, 발령문, 「발령한 날부터 시행」 |
   | 지방자치단체 | 조례·규칙(법제처 자치법규) | 입법예고, 의회 제출 조례안, 공포문, 「공포한 날부터 시행」 |

3. 기관명 칸에 이름 일부(예: 「창업」, 「수원」)를 치면 목록에서 고를 수 있습니다. 기관명은 문서의 기관명·결재권자(원장·시장·장관 등)에 쓰입니다. 비워 두면 「예시 기관」으로 진행합니다.
4. <b>「무엇을 하시겠어요?」</b> 에서 할 일을 고르거나, 머리글의 기능키 단추(F1~F12)를 누릅니다. 키보드 F1~F10도 됩니다(F5는 브라우저 새로 고침).

> 기관 유형이나 기관명을 바꾸면 앞 기관으로 진행하던 개정·제정 화면과 비교·점검 결과는 비워집니다(다른 기관 문안이 섞이지 않게).

---

## 2. 규정 고치기 — F2 개정

**언제**: 상위 법령 개정, 감사 지적, 제도 개선으로 기존 규정의 조문을 고칠 때.

**순서**

1. **F2 개정** → 왼쪽에 절차 단계(규정과 개정 의도 → 초안 만들기 → 초안 검토 → 관계 부서 협의 → … → 공포·공시)가 보입니다.
2. 고칠 규정을 고릅니다.
   - <b>기관 규정(ALIO)</b> 탭: 기관명 일부와 규정명·주제(예: 「창업진흥원」, 「복무규정」)로 찾아 고릅니다.
   - **파일·붙여넣기** 탭: hwpx·txt·md 파일을 올리거나 원문을 붙여넣습니다.
3. **개정 의도**를 문장으로 적습니다. 아래 예시 단추를 눌러 채울 수도 있습니다.
   - 예: 「남녀고용평등법 개정에 맞춰 배우자 출산휴가를 20일로 늘리고 청구기간을 120일로 바꾼다」
4. <b>「초안 만들기」</b> 를 누릅니다. 진행 상황이 단계별로 보이고, 담당자 확인이 필요하면 화면에 선택지가 나옵니다(알림음이 울립니다).
   - <b>조문·근거 확인(한 화면)</b>: AI가 추천한 조문과 참고할 근거가 체크되어 있습니다. 추천대로면 **Enter**(또는 「확인하고 계속」)를 누르고, 바꿀 것은 숫자 키(1～9)나 클릭으로 켜고 끕니다. 규정에 그 주제 조문이 없으면 「새 조문을 둘 자리」로 안내합니다.
   - 확인 화면을 보는 동안 추천대로 초안을 **미리 씁니다**. 추천을 그대로 받으면 결과가 바로 나오고, 조문을 바꾸면 그 조문으로 근거를 다시 찾아 새로 씁니다.
   - 대상 조문이 분명하면(추천 1개가 제목이 주제와 맞는 유일한 조문이고 근거가 적을 때) 묻지 않고 진행하며, 체크리스트에 그렇게 적습니다.
   - 「초안 만들기」 옆 <b>「추천대로 진행(확인 생략)」</b>을 켜면 확인 없이 끝까지 만듭니다(기본 꺼짐, 이 브라우저에 기억). F3 제정·F4 대화로 요청에도 있습니다.
5. 결과(초안 검토 단계)
   - **개정문**: 「제7조제2항 중 "10일의"를 "20일의"로 한다」 같은 부분 개정 또는 「제7조를 다음과 같이 한다」 전부 개정 문형
   - **신구조문대비표**: 바뀐 부분 밑줄
   - **개정 후 전문**: 규정 전체에 수정안을 반영한 본문. 바뀐 조문 제목 뒤에 〈개정〉〈신설〉〈삭제〉〈조 번호 이동〉을 표시하고, 이번 부칙은 기존 부칙 뒤에 붙입니다
   - **개정 이유서·부칙·예고문**, **검토 체크리스트**(자체 검토로 고친 점, 남은 문제, 단체협약·불이익 변경·다른 규정 인용 확인 등)
   - 문서 본문은 화면에서 바로 고칠 수 있고, 고친 내용 그대로 내려받습니다(Markdown, 문서(HTML·인쇄용), 대비표 CSV).
6. 왼쪽 단계를 차례로 눌러 **협의·심의·공포** 단계에 필요한 서식(협조 요청 공문, 근로자 의견 청취서, 법무 검토 의뢰서, 심의 안건, 이사회 부의안, 공포·발령문 등)을 받습니다.

**주의**: 밑줄 친 문서 이름(근거·타 기관 조항)을 누르면 **원문 보기**가 열려 해당 조항과 문서 전체를 확인할 수 있습니다. 「처음부터 다시」는 「새로 시작」을 누릅니다.

### 2-1. 받은 의견 반영하기(관계 부서 협의 단계)

1. 초안을 만든 뒤 왼쪽 <b>「관계 부서 협의」</b> 단계를 엽니다.
2. <b>「받은 의견 반영하기」</b> 칸에 회신 의견을 붙여넣습니다.
3. <b>「처리안 만들기」</b> → 의견마다 처리안(반영·일부 반영·미반영)과 사유가 나옵니다. 반영할 의견을 담당자가 고릅니다.
4. 결과: **의견 검토서**(의견마다 처리·대상 조문·의견 요지·사유), 의견을 반영한 대비표·개정문. 부칙(시행일·경과조치) 의견은 「반영 · 부칙」으로 표시되고 사유에 부칙 반영안이 적힙니다.

## 3. 규정 새로 만들기 — F3 제정

**언제**: 새 지침·규칙을 만들 때.

1. **F3 제정** → 종류(규정·지침 등), **제명**(예: 「가나다공단 재택근무 운영지침」), **제정 목적**을 적습니다.
2. 상위 법령의 **위임 조항**이 있으면 「위임 조항 추가」로 넣습니다.
3. <b>「초안 만들기」</b> → 먼저 <b>조문 체계(장·조 목록)</b> 를 확인·수정한 뒤 진행합니다.
4. 결과: 조문 초안, 제정안·대비표(<신 설>), 제정 이유서, 부칙, 예고문, **위임 범위 검토표**, 절차 서식.

---

## 4. 문장으로 요청하기 — F4 대화로 요청

**언제**: 무엇을 눌러야 할지 모를 때. 하고 싶은 일을 한 문장으로 적습니다.

1. **F4 대화로 요청** → 예: 「창업진흥원 복무규정 배우자 출산휴가를 남녀고용평등법 개정에 맞게 고쳐줘」
2. 에이전트가 **실행 계획과 남은 단계**를 먼저 보여 주고, 규정 찾기 → 원문 불러오기 → 근거 조사 → 개정안 작성 → 절차 안내 순으로 실행합니다. 진행 기록이 실시간으로 보입니다.
3. 확인이 필요하면 선택지가 나옵니다(알림음).
4. 결과 문서 세트를 보고 <b>「절차 따라 이어 가기」</b> 를 누르면 F2 절차 화면으로 넘어가 협의·심의 단계를 이어 갑니다.

**참고**: 요청한 규정에 해당 주제 조문이 없으면 새 조문으로 만들고, 같은 기관의 다른 규정에 이미 있으면(예: 취업규칙에는 없고 복무규정에 있음) 체크리스트와 요약에서 알려 줍니다.

## 5. 필요할 때 쓰는 도구(F6~F10)

### F6 법 개정 영향
- **언제**: 상위 법령이 바뀌어 어느 규정을 고쳐야 하는지 찾을 때.
- **순서**: 법령명과 개정 전·후 조문을 넣고(<b>「예시 채우기」</b> 로 배우자 출산휴가 예시) 기관 범위를 정해 실행합니다.
- **결과**: 영향받는 규정 조문을 「반영됨 / 개정 후보 / 확인 필요」로 표시합니다. <b>「개정안 만들기」</b> 로 F2로 이어 갑니다. 시행예정 법령을 모아 보는 **정비 계획서**도 내려받을 수 있습니다.

### F7 기관 비교
- **언제**: 같은 주제를 다른 기관은 어떻게 정했는지 볼 때.
- **순서**: 우리 기관(예: 창업진흥원) → 비교 범위(같은 주무부처·같은 기관 유형·직접 고른 기관, 지방자치단체는 같은 시·도 등) → 주제(예: 배우자 출산휴가)를 정해 실행합니다.
- **결과**: 기관별 비교표(일수·기한 등 항목별 값)와 값 분포. 표의 조문을 누르면 원문, <b>「이 조문 개정하기」</b> 로 F2로 이어 갑니다. CSV로 받을 수 있습니다.

### F8 규정 점검
- **언제**: 규정 묶음이나 기관 전체 규정의 오류 후보를 찾을 때.
- **순서**: 파일(여러 개)을 올리거나 「ALIO 기관 전체」에서 기관을 고르고 <b>「점검 시작」</b>.
- **결과**: 인용 오류(없는 조·별표), 용어 혼용, 수치 충돌 후보, 규정 누락 확인. CSV로 받습니다. 모두 「후보」이므로 원문으로 확인합니다.

### F9 일괄 개정
- **언제**: 직제 개편·용어 통일을 여러 규정에 한꺼번에 반영할 때.
- **순서**: 규정 파일(여러 개)과 바꿀 말(예: 「근로자」 → 「직원」)을 넣고 <b>「바꿀 곳 찾기」</b> → 바꿀 곳마다 확인(합성어 의심은 기본 해제).
- **결과**: 규정별 개정문·대비표. 조사(은/는·이/가 등)를 맞춰 주고, 부칙·「」 안·법령명·「근로자의 날」 같은 고유 명칭·바꿀 말을 정의하는 문장은 건드리지 않습니다.

### F10 법령 체계
- **언제**: 법률 조문이 시행령·시행규칙·기관 규정으로 어떻게 이어지는지 볼 때.
- **순서**: 법령명을 넣고 조문을 고릅니다.
- **결과**: 위임 문구 → 하위 법령 → 기관 규정으로 이어지는 관계. 기관 규정 조문에서 F2 개정으로 이어 갑니다.

## 6. 원문 검색과 원문 보기(AI 없이)

- 머리글 <b>「검색」</b> 단추 또는 **Ctrl+K**(맥 ⌘K).
- 자료 범위(기관 내규·법령·단체협약·공시자료·전체, 중앙행정기관·지방자치단체는 법제처 행정규칙·자치법규), 검색 방식(키워드·의미·통합), 「본문까지」, 「기관별 1건」, 기관·주무부처로 거르기를 고릅니다.
- 결과를 누르면 **원문 보기** 창이 열립니다: <b>「해당 조항」</b> 과 <b>「문서 전체」</b> 탭, 법제처 자료는 국가법령정보센터 바로가기. 결과는 CSV로 받을 수 있습니다.

## 7. 설정

### F11 기관 설정
기관 유형·기관명·규정 심의 기구·결재권자·시행일 문구를 정합니다. 서식의 결재권자와 시행 문구가 여기에 맞춰집니다. 규정의 기관과 설정한 기관이 다르면 검토 체크리스트에 경고가 나옵니다.

### F12 모델 설정
- 기본은 <b>서버 모델(GPT-OSS 120B)</b> 이라 키 없이 쓸 수 있습니다. 서버 모델은 하루 호출 한도가 있습니다.
- 공급자(EXAONE·OpenRouter·NVIDIA NIM·사용자 지정 OpenAI 호환 주소)와 모델을 고르고 **본인 API 키**를 넣을 수 있습니다.
- <b>법제처 Open API 인증키(OC)</b> 를 넣으면 본인 키로 법제처 자료를 조회합니다(비우면 서버 연결 사용).
- 입력한 키는 **이 브라우저 탭에만** 보관되고 요청할 때만 서버로 전달됩니다. 서버는 저장·기록하지 않으며 탭을 닫으면 사라집니다.

### 알림음
AI가 작업하는 동안 화면을 지켜보지 않아도 됩니다. 담당자 확인이 필요하면 부드러운 세 음, 끝나면 두 음, 실패하면 낮은 두 음이 울리고, 다른 탭을 보고 있으면 탭 제목에 「● 확인 필요」가 표시됩니다. 머리글의 **종 단추**로 끄고 켭니다(기본: 켜짐).

## 8. 자주 묻는 점

| 상황 | 안내 |
|---|---|
| 초안이 오래 걸려요 | 서버 모델 기준 개정 약 15～40초, 대화로 요청 약 30초～1분입니다. 서버가 붐비거나 EXAONE을 고르면 몇 분 걸릴 수 있습니다. 진행 기록에 단계별 소요 시간이 보입니다. |
| 새로 고침하면 작업이 없어지나요? | 같은 탭에서 새로 고치면 진행 중이던 작업을 이어받습니다(서버 보관 1시간). 화면이 이상하면 「새로 고침」 안내가 나옵니다. |
| 검색 결과가 0건이에요 | 낱말을 줄이거나 「의미」·「통합」 검색으로 바꿔 보세요. 법제처 자료는 기관 이름을 비우거나 「본문까지」를 켭니다. 조회 실패는 화면에 따로 표시되며, 0건이 「없음」을 뜻하지 않을 수 있습니다. |
| 「모델 설정」 안내가 나와요 | 서버 모델 하루 한도를 넘었거나 모델 연결이 안 되는 경우입니다. F12에서 본인 키를 넣으면 계속 쓸 수 있습니다. 검색·원문·대비표·점검은 모델 없이도 됩니다. |
| hwp 파일이 안 올라가요 | 한글(hwp) 바이너리는 읽지 않습니다. 한글에서 hwpx로 저장해 올리거나 원문을 붙여넣으세요. |
| 올린 파일은 어떻게 되나요? | 원본은 읽기 전용으로 보관하고 24시간 뒤 자동 삭제합니다. |
| 결과를 믿어도 되나요? | AI 초안입니다. 근거·원문 보기와 검토 체크리스트로 대조한 뒤 담당자가 확정하세요. 실행할 때마다 표현이 조금 다를 수 있습니다. |
